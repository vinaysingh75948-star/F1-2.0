## 📌 About the Project

**F1 2.0** is a responsive, multi-page personal portfolio website designed to establish a professional online presence.

The website provides a structured platform to showcase personal information, introduce services, display portfolio projects, highlight team members, and share content through a blog section.

Built using HTML, CSS, JavaScript, and Bootstrap, the project focuses on clean UI design, responsive layouts, smooth navigation, and an engaging user experience.

The project is intended to serve as a foundation for a professional portfolio or business website that can be further customized according to individual requirements.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including desktops, tablets, and mobile devices.
- **Modern Landing Page:** A visually engaging homepage with a hero section and navigation.
- **About Section:** Provides an introduction and information about the website owner.
- **Services Section:** Displays services and areas of expertise.
- **Portfolio Section:** Organizes projects into categories such as apps, products, and web projects.
- **Team Section:** Displays team members and their professional information.
- **Pricing Section:** Provides a structured pricing layout.
- **Blog Section:** Supports articles and content presentation.
- **Dashboard Page:** Includes a separate dashboard interface.
- **Story Page:** Provides a dedicated page for storytelling or additional information.
- **Contact Forms:** Includes form-related resources for user interaction.
- **Animations:** Uses visual effects and scroll animations to improve the browsing experience.
- **Reusable Components:** Uses organized CSS, JavaScript, and vendor resources.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

You need:

- A modern web browser (Chrome, Edge, Firefox, etc.).
- Visual Studio Code or another code editor.
- Live Server extension (recommended).

No Node.js installation or backend server is required for basic static website viewing.

### 1. Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/vinaysingh75948-star/F1-2.0.git
```

### 2. Navigate to the Project Directory

```bash
cd F1-2.0
```

### 3. Open the Project

Open the folder in Visual Studio Code:

```bash
code .
```

### 4. Run the Website

**Option 1: Using Live Server**

1. Install the Live Server extension in VS Code.
2. Open the `index.html` file.
3. Right-click anywhere inside the file.
4. Select **Open with Live Server**.

**Option 2: Using a Browser**

Simply open `index.html` in your preferred browser.

The website should now be accessible locally.

> Note: If styles, images, or scripts fail to load, verify that the asset paths in the HTML files match the actual folder structure.

## 🌐 Deployment

The website can be deployed using static hosting services such as:

- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://www.netlify.com/)
- [Vercel](https://vercel.com/)

For GitHub Pages, open your repository:

1. Navigate to **Settings**.
2. Select **Pages**.
3. Choose the `main` branch.
4. Select the root folder (`/`).
5. Click **Save**.

Once deployment is complete, GitHub will provide a public website URL.
